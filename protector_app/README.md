# Protector Management

Local Flutter CRUD app for **Protectors** and **Mobile Models**.

## Features

- Create / edit / delete Protectors
- Multiple mobile models per Protector
- Unique MobileModel master list (case-insensitive)
- Autocomplete for mobile models
- Search by protector name or mobile model
- Offline SharedPreferences JSON storage

## Run

```bash
cd protector_app
flutter pub get
flutter run
```

## Note

If Flutter/Dart is blocked by Device Guard on Windows, allow:

`C:\flutter\bin\cache\dart-sdk\bin\dart.exe`
